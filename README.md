# 📧 Automatic Email Sender (VBA Project)

## 📌 Overview
This project is a **bulk email sender built with VBA (Visual Basic for Applications)**.  
It allows you to automatically send emails from **Microsoft Outlook** (via Excel or Word VBA) to multiple recipients in just one click.

- Emails follow a **fixed predefined message template**  
- Multiple recipients can be added at once  
- Saves time by automating manual email sending  

---

## 🚀 Features
- ✅ Send emails in bulk automatically  
- ✅ Fixed message body (customizable in VBA code)  
- ✅ Uses Outlook for secure email delivery  
- ✅ Easy to use, no third-party tool required  
- ✅ Ideal for **announcements, notifications, or reminders**  

---

## 🛠 Requirements
- Microsoft Windows  
- Microsoft Excel (with VBA enabled)  
- Microsoft Outlook (configured with your email account)  

---

## 📂 Setup Instructions
1. Open **Excel / Word VBA editor** (`Alt + F11`).  
2. Insert a **Module** and paste the provided VBA code.  
3. Update the following in the VBA script:  
   - `Recipients List` → Add email addresses (can fetch from Excel column).  
   - `Subject Line` → Fixed subject for your bulk emails.  
   - `Body Message` → Fixed text to send in every email.  
4. Save the file as **Macro-Enabled Workbook** (`.xlsm`).  
5. Run the macro → Emails will be sent automatically through Outlook.
